# Local SEO: Google Business Profile and citations

## Before you create or edit the profile (blocking)

1. **Address eligibility.** Google requires a real location staffed during stated hours where customers can visit. Confirm that Chamber No. 698, Tis Hazari Court can be used by a consultancy, that someone is there during the listed hours, and that you can show permanent signage. If staff are not there during the listed hours, set the profile up as a **service-area business** with the address hidden.
2. **Bar Council rules.** If an advocate practises from that chamber, check with them that a commercial listing at the chamber address is permitted (MANUAL_ACTIONS L2).
3. **Final NAP** (name, address, phone) and hours — decisions D3/D4. Use exactly the same text everywhere.

## Reviews

- Ask every client after the work is complete, with a direct review link. Same request for everyone — no review gating (asking only happy clients).
- No incentives, discounts or gifts for reviews. Never write reviews for yourself or ask staff/family to.
- Reply to every review politely without confirming that the reviewer is a client or mentioning any loan details.
- Never paste review quotes onto the website without the reviewer's permission.
